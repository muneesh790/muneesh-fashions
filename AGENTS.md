# Muneesh Fashions

We are building a V1 clothing e-commerce application.

Tech stack:
- Frontend: React.js
- Backend: Node.js + Express.js
- Database: MongoDB Atlas + Mongoose
- Image storage: ImageKit
- Payments: Razorpay

Architecture:
- Customer React application
- Admin React application
- Express REST API
- MongoDB Atlas

Important development rules:
- Do not blindly generate the entire application.
- Implement one feature at a time.
- Explain the architecture before coding.
- Explain important code after implementation.
- Keep V1 simple.
- Do not introduce unnecessary technologies or libraries.
- Never expose secrets in frontend code.
- Payment verification must happen on the backend.
- Admin APIs must have authorization.
- Write clean, beginner-friendly code.
